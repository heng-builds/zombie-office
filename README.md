# 殭屍辦公室：活著下班

像素風的辦公室殭屍生存射擊遊戲。整棟公司的人都變成殭屍了，主角是一名上班族，要帶著文具槍從 1F 一路殺上 25F，把主管和老闆都打下班。

整個遊戲是單一個 `index.html`，不需要安裝任何東西，用瀏覽器打開就能玩。

## 玩法

- 共 6 層樓，每層有一位魔王：碎念組長、KPI 經理、甩鍋副理、HR 裁員專員、大老闆、董事長
- 擊倒指定數量的殭屍同事後，該層魔王會登場，打倒魔王即可解鎖下一層
- 射擊是全自動的，會瞄準最近的敵人，玩家只需要走位和換槍
- 出發前從武器庫挑兩把槍；關卡中撿到槍箱會升級手上的槍，或換成武器庫裡的另一把
- 關卡中可撿到技能便利貼、便當（補血）、槍箱，這些效果只在當局有效
- 金幣可以在武器庫買槍、在更衣室買服裝；槍枝與服裝分為普通、稀有、史詩、傳說四個等級

## 操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD 或方向鍵 | 左手在畫面上拖曳 |
| 射擊 | 自動 | 自動 |
| 換槍 | Q／E、數字鍵 1／2、滑鼠滾輪、右鍵 | 右下「換槍」按鈕 |
| 暫停 | Esc 或 P | 右上暫停按鈕 |

## 存檔

金幣、已購買的槍枝和服裝、已解鎖的樓層都存在瀏覽器的 localStorage 裡，每局遊戲結束後自動儲存。換電腦、換瀏覽器或清除瀏覽資料後，進度不會保留。設定頁面可以清除存檔。
