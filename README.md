# 殭屍辦公室：活著下班　Zombie Office

> 目前版本：v0.30.7

公司裡的同事全變成殭屍了。你手上只有釘書機手槍和一條領帶——從 B1 停車場一路往上殺到頂樓，打倒變成殭屍的主管和董事會，活著下班。

**直接在瀏覽器玩**，手機、平板、電腦都可以。也可以「加入主畫面」當成 App 使用，離線也能玩。

---

## 怎麼玩
- **移動**：電腦用 WASD 或方向鍵；手機用左半邊螢幕拖曳。
- **射擊是自動的**：會自動瞄準最近的殭屍。
- **閃避**：電腦按空白鍵；手機按「閃避」。閃避的瞬間無敵。
- **切換武器**：電腦按 Q、E 或滑鼠右鍵；手機按「切換」。
- **換槍**：站在橘色槍箱旁，電腦按 F；手機按「撿槍」。
- **暫停**：電腦按 Esc 或 P；手機按右上角的暫停鍵。
- **升等**：撿起考績單（經驗）升等，從三張卡片中選一張強化。
- **撿東西**：金幣、便當（補血）、便利貼（短時間加成）、槍箱（升級或換槍）。

## 遊戲模式
| 模式 | 內容 |
| --- | --- |
| 開始上班 | 從 B1 停車場往上打，每層樓有不同的機關和主管魔王 |
| 每日挑戰 | 每天一關固定規則的挑戰，和所有人比當天成績 |
| 無限加班 | 撐越久越好，殭屍越來越多，公司最後會倒閉 |
| 爬樓 | 一路從 B1 爬到頂樓，途中選路線、遇事件、逛便利商店 |
| 午休保衛戰 | 保護便當，撐過午休時間 |

## 成長與收藏
- **武器庫**：28 把辦公室武器，從釘書機手槍到董事長的武士刀。
- **更衣室**：24 套服裝，每套都有不同能力。
- **人事室**：用金幣升級年資加成、購買搞笑福利和職稱。
- **員工證**：自訂外觀與名字，排行榜上會顯示你的員工證。
- **成就職稱**：完成特殊挑戰解鎖。

## 排行榜
無限加班、每日挑戰、各樓層、午休保衛戰、爬樓都有排行榜。上傳成績時只會傳送遊戲成績與員工證外觀，詳細內容請見遊戲內「設定 → 隱私說明」。

## 回饋
遊戲內「設定 → 回報問題」可以直接回報問題或建議。
