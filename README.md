# 殭屍辦公室：活著下班

目前版本：v0.9.1

像素風的辦公室殭屍生存射擊遊戲。整棟公司的人都變成殭屍了，主角是一名上班族，要帶著文具槍從 1F 一路殺上 25F，把主管和老闆都打下班。

整個遊戲是單一個 `index.html`，不需要安裝任何東西，用瀏覽器打開就能玩。

## 玩法

- 共 11 層樓：碎念組長、KPI 經理、會計主任、甩鍋副理、HR 裁員專員、資訊長、大老闆、法務長、董事長，頂樓 RF 是三位董事同時登場的董事會；10F 員工餐廳是沒有魔王的午休保衛戰，15F 資訊部機房會停電
- 打穿 RF 後解鎖「無限加班」模式：殭屍越來越多，每 60 秒隨機一位主管來巡視，撐越久分數越高
- 擊倒指定數量的殭屍同事後，該層魔王會登場，打倒魔王即可解鎖下一層
- 射擊是全自動的，會瞄準最近的敵人，玩家只需要走位和換槍
- 出發前從武器庫挑兩把槍。關卡中的槍箱分兩種：綠色會升級手上的槍，自動撿起；橘色可以換成另一把，要按 F（手機按「撿槍」）才會換，換下來的槍會掉在原地
- 關卡中可撿到技能便利貼、便當（補血）、槍箱，這些效果只在當局有效
- 金幣可以在武器庫買槍（15 把）、在更衣室買服裝（20 套）；分為普通、稀有、史詩、傳說四個等級，許多服裝有專屬能力
- 第一次啟動會先製作員工證（捏角色）：姓名、膚色、髮型、髮色、臉部配件，之後也可從主選單修改
- 1F 有簡短的操作提示；設定裡有「輕鬆模式」可降低難度，不影響金幣與解鎖

## 操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD 或方向鍵 | 左手在畫面上拖曳 |
| 射擊 | 自動 | 自動 |
| 切換手上的槍 | Q／E、數字鍵 1／2、滑鼠滾輪、右鍵 | 黃色「切換」按鈕 |
| 撿槍箱換槍 | F | 藍色「撿槍」按鈕 |
| 衝刺（外送員制服） | 空白鍵 | 藍色「衝刺」按鈕 |
| 暫停 | Esc 或 P | 右上暫停按鈕 |

## 存檔

設定頁面可以分別開關配樂、槍聲、其他音效，各自調整音量。配樂由程式即時合成，不需要音樂檔。每層樓有各自的房間佈局、牆面裝飾與佈景。

金幣、已購買的槍枝和服裝、已解鎖的樓層、捏好的角色都存在瀏覽器的 localStorage 裡，每局遊戲結束後自動儲存。換電腦、換瀏覽器或清除瀏覽資料後，進度不會保留。設定頁面可以清除存檔。

## 部署到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `zombie-office`），設為 Public
2. 把 `index.html`、`README.md`、`.nojekyll` 上傳到 repository 根目錄
3. 到 repository 的 **Settings → Pages**
4. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
5. 等一到兩分鐘，網址會是 `https://<你的帳號>.github.io/zombie-office/`

之後修改 `index.html` 並推上 `main`，網站會自動更新。

## 檔案說明

- `index.html`：遊戲本體，包含所有程式、樣式與像素圖
- `.nojekyll`：讓 GitHub Pages 直接提供檔案，不經過 Jekyll 處理
- `README.md`：本說明

字型從 Google Fonts 載入（DotGothic16、Noto Sans TC），離線時會自動改用系統字型。
